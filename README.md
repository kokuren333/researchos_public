# Research OS Public

Reusable, auditable infrastructure for connecting Sources, Evidence, Claims, Concepts, and public Field models.

This repository contains public knowledge infrastructure only. Private research ideas, unpublished manuscripts, restricted datasets, and credentials belong in `researchos_private`.

## Status

The public repository now provides the reusable epistemic core, six-domain Concept browser, five Skills, Execution Contracts, and a minimal Workflow Runtime. Research projects, manuscript generation, autonomous agents, and private research materials remain out of scope.

Concept pages distinguish `mapped` (map entry/stub) from `deepened` (content-backed). Runtime and Workflow outputs are generated under `dist/` and are not source-controlled.
