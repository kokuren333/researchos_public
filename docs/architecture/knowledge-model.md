# Knowledge Model

- **Source**: a re-accessible original document or dataset.
- **Evidence**: a located extraction from a Source; generated prose is never Evidence.
- **Claim**: a statement linked to supporting or contradicting Evidence.
- **Concept**: a stable knowledge unit with relations and prerequisites.
- **Field**: a public map of a discipline, including questions, methods, debates, failure modes, and canon metadata.

The initial validator enforces Source/Evidence/Claim/Concept references without implementing a research-project workflow.
