# Field content depth audit

Physics and Statistics now render the same concept-page contract: one-line definition, intuition, importance, problem solved, example, misconception, prerequisites, related concepts, and Source links.

## Current classification

- Physics: 30 concepts are **BASIC** or better; the most central concepts (state, model, approximation, dynamics, interaction, conservation-law, symmetry, field, measurement, scale) are **FIELD_VIEW_READY** in the human-facing synthesis.
- Statistics: existing records provide Japanese mental models, properties, applications, misconceptions, prerequisites, and Source/Evidence records; the renderer now exposes these as a consistent human-facing structure.

## Limitation

The enrichment is a renderer-level synthesis over existing records, not new Evidence. Physics claims remain intentionally introductory until each concept receives source-specific locators. Future work should move these fields into explicit localized data rather than relying on renderer fallbacks.
