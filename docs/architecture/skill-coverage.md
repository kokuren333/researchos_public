# Skill coverage audit

Research OS の Skill は、`understand`、`appraise`、`design`、`analyze`、`synthesize` の taxonomy と、`SKELETON` / `BASIC` / `EXECUTABLE` / `AUDITED` の maturity を持つ。

監査結果は build 時に [`dist/generated/skill-coverage.json`](../../dist/generated/skill-coverage.json) として生成される。Concept coverage を100%にするのではなく、主要Conceptが実際の判断・分析・設計能力へ接続されているかを確認する。
